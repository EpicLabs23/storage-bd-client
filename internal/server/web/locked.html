Backup

Open this page from your terminal

For your security, this backup panel only opens through a private link, and the link changes every time the service restarts. To get the current link, run this on the machine being backed up:

storagebd ui-url

Using a remote server? Open a tunnel first, for example ssh -L 7878:127.0.0.1:7878 your-server, then open the link on this computer.
